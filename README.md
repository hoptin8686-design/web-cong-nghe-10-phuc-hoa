# Web Công nghệ 10 — Công nghệ Trồng trọt (THPT Phục Hòa)

Nền tảng học tập trực tuyến môn **Công nghệ 10 — Công nghệ Trồng trọt** dành cho học sinh Trường THPT Phục Hòa (Tỉnh Cao Bằng), bám sát chương trình SGK GDPT 2018 (Bộ sách Kết nối tri thức với cuộc sống).

## 🌟 Tính năng nổi bật

1. **8 Chương & 28 Bài học chuẩn**:
   - Chương I: Giới thiệu chung về trồng trọt
   - Chương II: Đất trồng
   - Chương III: Phân bón
   - Chương IV: Công nghệ giống cây trồng
   - Chương V: Phòng trừ sâu, bệnh hại cây trồng
   - Chương VI: Kĩ thuật trồng trọt
   - Chương VII: Trồng trọt công nghệ cao
   - Chương VIII: Bảo vệ môi trường trong trồng trọt

2. **5 Phân hệ học tập tương tác trong từng bài học**:
   - 💡 **Lý thuyết tương tác**: Sơ đồ trực quan, bảng so sánh đối chiếu, các câu hỏi kiểm tra nhanh xen kẽ.
   - 🎯 **Trắc nghiệm 4 lựa chọn (MCQ)**: Tự động đảo đề và phương án, chấm điểm tức thì kèm giải thích chi tiết.
   - ⚖️ **Tư duy phản biện Đúng/Sai**: Định dạng đề mới của Bộ GD&ĐT với 4 mệnh đề độc lập.
   - 📝 **Tự luận & Vận dụng thực tiễn**: Khung nháp và hướng dẫn giải chi tiết.
   - 🏆 **Phòng thi thử & Ôn tập định kỳ**: Đề thi giữa kì và cuối kì có đồng hồ đếm ngược 45 phút.

3. **Lưu trữ tiến độ cá nhân hóa**:
   - Theo dõi số lượng sao vàng ⭐ đạt được (>=80% điểm).
   - AI gợi ý các bài học cần ôn luyện lại dựa trên lịch sử làm sai.

## 🛠️ Công nghệ sử dụng
- **Next.js 14** (App Router, SSG static pre-rendering)
- **TypeScript**
- **Tailwind CSS** (Giao diện sinh thái nông nghiệp hiện đại, dark mode)
- **Lucide Icons** & **Canvas Confetti**

## 🚀 Chạy trên môi trường cục bộ

```bash
npm install
npm run dev
```
Truy cập [http://localhost:3003](http://localhost:3003) trên trình duyệt.

## 📦 Biên dịch Production

```bash
npm run build
npm run start
```
